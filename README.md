# My Node.js Project

โปรเจกต์สำหรับฝึกพัฒนาโปรแกรมด้วย **Node.js และ JavaScript** โดยใช้ Visual Studio Code (VS Code) ในการเขียนและจัดการโค้ด และ GitHub สำหรับจัดเก็บโปรเจกต์

## About the Project

โปรเจกต์นี้จัดทำขึ้นเพื่อศึกษาและฝึกฝนการเขียนโปรแกรม รวมถึงการใช้งานเครื่องมือสำหรับพัฒนาซอฟต์แวร์

## Technologies Used

- **JavaScript** – ภาษาโปรแกรมหลัก
- **Node.js** – Runtime สำหรับรัน JavaScript
- **npm** – Package Manager
- **Visual Studio Code** – Code Editor
- **Git & GitHub** – Version Control และจัดเก็บโปรเจกต์

## Project Structure

MyProject/

## Installation

1. ติดตั้ง Node.js จาก https://nodejs.org/
2. ดาวน์โหลดหรือ Clone โปรเจกต์
3. เปิดโฟลเดอร์ด้วย VS Code
4. เปิด Terminal

## How to Run

```bash
node app.js
```
